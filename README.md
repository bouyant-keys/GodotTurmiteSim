## Purpose
This is my creative artefact for the Computing Theory course at RMIT.
Initially completed on October 18th 2026.

## 
This is a Turmite (2-Dimensional Turing Machine) Simulator constructed using the Godot game engine.
There are 5 presets for Langton's Ant, and 4 symmetric Ant varieties by [Jim Propp](https://arxiv.org/pdf/math/9501233).
There is also an instruction editor box to edit to presets or make your own instructions, following the format:

>Instruction = L,R,L,R,... (where L & R represent turns based on the tile-color.)<br>
>So, tile-color 4 -> Instruction[4] -> R (turn right). <br>

There are scripts & settings for further development (for example Turing Machine notation) which didn't make the cut.
Feel free to build upon this project and incorporate these if you want.
